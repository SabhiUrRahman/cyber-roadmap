# Cyber Roadmap

My week-by-week roadmap from zero to a first cybersecurity internship by September 2027: web application security first, then the security of AI-built apps.

**Live:** https://sabhiurrahman.github.io/cyber-roadmap/

- Works offline after the first visit and can be installed on a phone (browser menu → *Add to Home screen* / *Install app*).
- Ticks are saved in the browser on each device. Use **Copy my progress code** and **Load a progress code** to move them between phone and laptop.
- No accounts, no tracking: nothing leaves the device.
